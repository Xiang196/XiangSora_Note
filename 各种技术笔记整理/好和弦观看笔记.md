### 和弦的记法
七和弦，4个音的和弦
常用的七和弦——大，小，属
```music-abc
X:1
T:[1]常见的七和弦
M:4/4
L:1/8
K:C
[CEGB]8 | [C_EG_B]8 | [C=EG_B]8 |]
```
【大】七和弦：大调音阶的1,3,5,7音
【小】七和弦：将大七和弦的3,7音降半音
【属】七和弦：将大七和弦的7音降半音

相应的十三和弦，7个音的和弦，只要再往上面加大调音阶的9,11,13音
```music-abc
X:2
T:[2]常见的十三和弦
M:4/4
L:1/8
K:C
[CEGBdfa]8 | [C_EG_Bdfa]8 | [C=EG_Bdfa]8 |]
w: Cmaj13 Cm13 C13
```

和弦代号的组成：根音+字尾
大和弦：C, Cmaj7, Cmaj9...
小和弦：Cm, Cm7, Cm9...
属和弦：C7, C9, C11...

四种变化
**add**：增加音，例如Cadd2，就是在C和弦基础上添加2音
**sus**：将三度音换成二度/四度音，例如Csus2，Csus4（Csus）
**omit**：省略音，例如Cmaj9omit3
**( )**：例如Cmaj9(#5)
```music-abc
X:3
T:[3]和弦记名的变化
M:4/4
L:1/8
K:C
[CDEG]8 | [CDG]8 | [CFG]8 | [CGBd]8 | [CE^GBd]8 |]
w: Cadd2 Csus2 Csus4 Cmaj9omit3 Cmaj9#5
```

### 和弦的功能

```music-abc
X:9
T:[9]C大调和弦
M:4/4
L:1/8
K:C
[CEG]4[DFA]4|[EGB]4[FAc]4|[GBd]4[Ace]4|[Bdf]4[ceg]4|]
w: C Dm|Em F|G Am|Bdim C|
```
第一个和弦，**C：主和弦**
第五个和弦，**G：属和弦**
- 更不稳定的和弦，G7，掺杂了三全音
第四个和弦，**F：下属和弦**

比喻：**主和弦-家，下属和弦-桥，属和弦-外面**
**家→桥→外面→家**

这三种和弦可以相互连接，不过其中，属和弦→下属和弦是少见的
```music-abc
X:10
T:[10]和弦进行示例
M:4/4
L:1/8
K:C
[CEGc]8|[CFAc]8|[B,DFGB]8|[CEGc]8|]
w: (主)C|(下属)F|(属)G7|(主)C
```

第七个和弦，**Bdim：属和弦**
第二个和弦，**Dm：下属和弦**
第三和第六个和弦，**Em，Am：主和弦的延伸（暂时的“家”）**

简单的和弦连接表

| 家       | 桥    | 外面   | 家    |
| ------- | ---- | ---- | ---- |
| C       | F    | G、G7 | C    |
| C→Em    | Dm   | Bdim | Em→C |
| C→Am    | F→Dm |      | Am→C |
| C→Em→Am | Dm→F |      |      |
| C→Am→Em |      |      |      |

### 音程名称
“度”，从一个音念到另一个音，读出几个字就是几度
- 不管怎么升降，都不会影响度数，同一个音可能有不同的度，例如C→#D是2度，C→bE是3度

我们将数字分开：1458,2367
- 1458→完全
- 2367→大

在大调音阶里，每一个音与第一个音的距离，都叫做“完全”或“大”音程
```music-abc
X:11
T:[11]完全音程与大音程
M:4/4
L:1/8
K:C
[CC]4[CD]4|[CE]4[CF]4|[CG]4[CA]4|[CB]4[Cc]4|]
w: 完全1度 大2度|大3度 完全4度|完全5度 大6度|大7度 完全8度
```
2、3、6、7这组的其他形容词：减，小，大，增
1、4、5、8这组的其他形容词：减，完全，增

不同的组合形成了不同的音色

### 七种调式
将自然大调的起始音从Do到Si更换，可以生成7种调式的音阶
分别是：
1. Ionian
2. Dorian
3. Phrygian
4. Lydian
5. Mixolydian
6. Aeolian
7. Locrian
阴间口诀：*“我的霹雳猫阿洛”*

Ionian和Aeolian分别就是自然大小调
我们补充一个好用的自然小调和弦：*降六和弦Cm(b6)——恐怖，悬疑*
- 这其实是空洞骑士灵魂圣所配乐里一直环绕的和弦
```music-abc
X:17
T:[17]降六和弦
M:4/4
L:1/8
K:C
C_EG_A z4|[C_EG_A]8 |z8| (3A,CE (3FCE (3FCE (3FCE |A2 A2 A2 A2
```

**Dorian：神圣感**
代表作：Scarborough Fair(斯卡布罗集市)
关键音是*区别于小调的还原6音*
```music-abc
X:18

M:4/4
L:1/8
K:C

```

**Phrygian：西部感**
关键音是*区别于小调的降2音*
*Phrygian-Dominant*的1音和弦和2音和弦都是大三和弦

**Lydian：华丽感**
关键音是*区别于大调升高的4音*
可以有一个*Cmaj13(#11)的好用和弦（梦幻感，科技感）*


**Mixolydian：开朗感**
关键音是*区别于大调降低的7音*
主题：*蓝调与爵士音乐*
与*属七和弦C7*非常好搭配
```music-abc

M:4/4
L:1/8
K:C
C2D2E2F2G2A2_B2c2|[CEG_B]8
```

**Locrian：黑暗感**
关键音是*区别于小调降低的2、5音*
主和弦是一个*减三和弦Cdim*

```music-abc
L:1/8

```

### 伴奏简单的变化：加入ghost note
为简单的和弦伴奏加入ghost note可以增加变化

- 四分音符变为两个八分音符（第二个音弱）

### 终止式

正格终止：五级和弦→一级和弦
- 以C大调为例，是G7→C
- 结束感
半终止：结尾是五级和弦
- 以C大调为例，是G7
- 还没结束感

假终止：五级和弦→六级和弦（一般）
- 以C大调为例，是G7箭头Am
- 听起来比较忧郁
```music-abc
X:32
T:[32]假终止
M:4/4
L:1/8
K:C
[C,EG]4 [F,A,C]4 | [G,B,F]4 [C,EG]4 | [G,,F,B,D]8 | [A,,E,A,C]8
w:  | |G7|Am
```
- 其他版本
	- 梦幻神圣感：G7→Ab
	- 慵懒感：G7→Dbmaj9
	- 紧张感：G7→F#dim7



### 走路低音 Walking Bass

一般指的是由均匀的四分音符组成的低音旋律，下面有几个写作技巧
1.  分解和弦，将和弦分成四分音符一个个写出
2. 和弦内变化，不简单的一个一个往上爬，而是在确保第一个音是根音的基础上，让音高跳跃一些
3. 加入经过音，在每一小节，例如C和弦，可以加入一个D音经过
4. 半音衔接，每一小节结尾的音可以选取下一小节开头音的升/降半音
5. 变化节奏，加入三连音，八分音符等

```music-abc
K:C

```

### 小十一和弦的用法

小十一和弦，就是将大十一和弦的3音和7音降半音

和弦的音高密集排列→纠结
和弦的音高分散排列→开阔

简单的做法是，将最低音降低两个八度，次低音降低一个八度
开阔的做法是，五度五度错开，CGDEBG→听起来梦幻，温柔
省略的做法是，omit5，omit9，形成Cm7add1

### 减和弦

减和弦是从根音开始由小三度堆叠而成
由于堆叠到第五个音就会重复，减和弦分为减三和弦和减七和弦
```music-abc

M:4/4
L:1
K:C
[C_E_G]|[C_E_G__B]
w:Cdim | Cdim7
```
经常用来渲染紧张场景

- 也可以作为一个属和弦，例如替代G7等
