# 上一
1. **词**：诗歌的一种。词体萌芽于隋唐之际 (一说南朝), 形成于唐代，盛行于宋。因句子长短不一，也称*长短句*。古代的词是配曲歌唱的，故又称为*曲子词、乐府、琴趣*等。
2. **词牌**：填词用的曲调名。最初的词，都是配合曲调歌唱的，有的按词制调，有的依调填词，*曲调的名称即词牌*，一般根据词的内容而定。后来词的创作形式主要为依调填词，而且大多数词都已不再配乐歌唱，所以词牌和词的内容不一定有内在的联系，词牌只作为文字、音韵结构的定式。
3. **新诗**：指*五四运动前后*产生的、以*白话*作为基本语言手段，有别于古典诗歌的诗歌体裁。其主要特点是表达现代人丰富复杂的思想感情，自由成章而*没有固定的格律*，*语言接近口语*而不尚典雅雕琢。
# 上二
1. **新闻**：指*新闻文体*。广义的新闻包括消息、通讯、特写等体裁。*狭义的新闻专指消息*。
2. **消息**：新闻体裁名，其特点是*简要、直接、迅速*地报道新闻事实。
3. **通讯**：新闻报道体裁。对于新闻人物与事件的记叙要比消息*具体、详尽、生动*。写作中多采用*叙述、描写、议论、抒情*并举的方法，寓理于事，以情动人。
4. **人物通讯**：写*一个人或一类人*，一群人的新闻报道文章。人物通讯以叙述人物的事迹、刻画人物的个性，展现人物的思想为主。
5. **新闻评论**：就当前具有普遍意义的新闻事件和重大问题发表议论、讲道理，有着鲜明*针对性和指导性的一种政论文体*，是所有新闻传播工具的各种形式评论的总称，属于*论说文*的范畴。
6. **《诗经》**: *我国最早的诗歌总集*，收录了从*周初*至*春秋中叶*的诗歌，共 *305* 篇，本只称《诗》, 儒家列为经典之一，故称《诗经》。《诗经》分为《风》《雅》《颂》, 在思想内容包括：反映劳动生产的诗篇，反对剥削和压迫的诗篇，反映征战、徭役和离乱的诗篇，反映爱情和婚姻的诗篇，反映社会黑暗腐朽的政治讽刺诗篇，古老的祭歌与颂扬祖先创业功绩的史诗等。《诗经》中诗篇的形式以四言为主，运用*赋、比、兴*的手法，在章法上具有*重章叠句、反复咏唱*的特点。诗经六义指：*风、雅、颂、赋、比、兴*。
# 上三
1. **古体诗**：诗体名，与近体诗相对。唐代将*周秦汉魏不讲究格律的诗*称为 “古体诗”，亦称 “*古风*”。“古体诗” 的特点是每篇*句数不拘*，*不求对仗*，平仄和用韵也较自由。从句式上，古体诗大致可分为四言、五言、六言、七言、杂言等。
2. **近体诗**：诗体名，与古体诗相对。唐代将齐梁以来开始流行的格律诗称为 “近体诗”，亦称 “*今体诗*”。它的特点是*数、字数、属对、平仄和用韵都有严格的规定*。根据诗歌句数，大致可分为*律诗和绝句*两类。
3. **律诗**：诗体名，近体诗的一种。因格律要求严格，故名 “律诗”。律诗起源于南北朝，成熟于唐初。律诗的主要特点是：每首诗共*八句四联* (分别为*首联、颔联、颈联、尾联*); *中间两联 (颔联、颈联) 必须对仗*；双句押韵，首句可押可不押，通常押平声。律诗大致可分五言律诗和七言律诗两类，简称*五律、七律*。另有句数在 *8 句以上者*，称为 “*排律*”。
# 上四
1. **访谈**  
    1. 概念：访谈是一种交谈活动，以口头形式，围绕特定目的，根据被询问者的答复，搜集客观的，不带偏见的事实材料，以准确地说明问题。  
    2. 访谈的一般流程：确定访谈的目的，功能以及理由；确定访谈的时间及进度；选择有代表性的访谈对象，确定访谈形式，设计问题。  
    3. *访谈问题的设计*：*要紧扣访谈的目的*，清晰具体，简单明白，易于回答；这些问题要*具体明确、层层深入*，有利于现象的梳理与挖掘；*提问的方式、用词的选择、问题的范围*要适合被访者的知识水平和习惯；如有可能也可以事先发给访谈对象访问提纲，*让访谈对象提前做好准备*。
2. **人物和风物志**  
    - 志，是记录的意思，“志” 是古代记叙事物、抒发情感的一种文体，所谓*风物志*，是指对家乡风光景物、风俗物产的介绍。地方*人物志*，记载地方上的人物，既可以记载名人，如近，现代革命英烈、劳动模范、优秀教师、能工巧匠、社会名流、专家学者等；也可以记载有一技之长或有独特经历的普通人。  
    - 常见的*风物志*要素：写作事由、风物渊源、特色风貌、文化价值。  
    - 常见的*人物志*要素：人物生平、主要事迹、重要贡献、社会影响。
3. **调查报告**  
	1. 概念解说：调查报告是*反映对某个问题，某个事件或某方面情况调查研究所获得的成果*的文章。它可以在报刊上发表，也可以供领导机关作为处理问题、制定政策的依据或参考。  
	2. 常见类型：介绍典型经验的调查报告、揭露问题的调查报告，反映新生事物的调查报告、社会情况的调查报告。  
	3. 对家乡文化生活的调查报告的*一般要素*：调查时间、调查地点、调查对象、调查方法、调查目的、调查内容。  
4. **建议书**  
	- 建议书是面*对有关部门或上级领导提建议时使用*的一种书面材料。*格式与一般书信大体相同*：标题、称呼、正文、结尾、署名、日期。  
	- 建议书的对象可以是家乡的相关部门，要注意*语言表达的得体*。因为作者的身份是中学生，建议对象是有关部门，所以应该是委婉的建议。对部门的建议可以以理性分析为主，简要陈述建议的内容、建议的理由、实施的步骤和可行性等，要有理有据。
# 上六
1. **荀子**，名况，字卿，战国末期赵国人。著名思想家、文学家、教育家，时人尊称 “荀卿” 。荀子对儒家思想有所发展，在人性问题上，*主张 “性恶论”*，认为人性有恶，否认天赋，强调后天环境和教育对人的影响。其学说常被后人拿来跟孟子的 “性善论” 比较。
2. **韩愈**，字退之，河南河阳 (今河南孟州南人)，自称 “郡望昌黎”，世称 “韩昌黎”“昌黎先生” 。唐代杰出的文学家、思想家、哲学家、政治家，*古文运动的倡导者*，被尊为 *“唐宋八大家” 之首*，有 “文章巨公” 和 “百代文宗” 之名。著有《韩昌黎集》等。
3. **“说”** 是一种文体，可先叙后议，也可夹叙夹议，都是为了*说明一个道理*，接近于现代的杂文，如《师说》《捕蛇者说》 。说，古义为陈述和解说，可理解为 “*解说…… 的道理*” 。
4. **六艺经传**的 *“六艺”* 是指儒家的六部经典，*即《诗》《书》《礼》《乐》《易》《春秋》*，也叫 *“六经”* 。*“传” 指传记，古代解释六经的著作，如《春秋左氏传》* 。
# 上七
1. **赋**：介于*诗和散文之间的一种文体*，特点是 “*铺采摛文，体物写志*” 。最早出现于诸子散文中，叫 “*短赋*”；以屈原为代表的 “骚体” 是诗向赋的过渡，叫 “*骚赋*”；汉代正式确立了赋的体例，称为 “*辞赋*”；魏晋以后，日益向对方向发展，叫作 “*骈赋*”；唐代又由骈体转入律体叫 “*律赋*”；宋代以散文形式写赋，称为 “*文赋*” 。著名的赋有：杜牧的《阿房宫赋》、曹植的《洛神赋》、欧阳修的《秋声赋》、苏轼的《前赤壁赋》等。
2. **干支纪年**：中国古代的纪年方法，一般认为始于汉朝。“干支” 是天干和地支的总称，*天干指甲、乙、丙、丁、戊、己、庚、辛、壬、癸，地支指子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥*，将十天干与十二地支按顺序两两相配，第一组为甲子年，循环一周，到下一个甲子年，*正好 60 年，叫一甲子*，干支纪年，周而复始，循环记录。
3. **记**：古代的一种*散文*体裁，通过*记事、记物、记人、写景来抒发作者的感情或见解*。可分为碑记、游记、杂记等。
# 下一
1. *《论语》：孔子弟子及其再传弟子编纂的记录孔子及其弟子言行的作品*，是儒家经典之一。
2. **千乘之国**：有 *1000 辆兵车*的诸侯国。在春秋后期，千乘之国是*中等国家*。乘，*古时一车四马为一乘*。春秋时，一辆兵车，配*甲士 3 人，步卒 72 人*。
3. **师旅**：指军队。*古时 2500 为一师，500 为一旅*。
4. **宗庙之事**：指诸侯祭祀祖先的事。在古代是国家重要的政事。宗庙，天子、诸侯供奉祖宗牌位的处所。
5. **会同**：古代诸侯朝见天子的通称。*会，诸侯在非规定时间朝见天子。同，诸侯一起朝见天子*。
6. **端章甫**：穿着礼服，戴着礼帽。这是做小相时的穿戴。*端，古代的一种礼服。章甫，古代的一种礼帽*。
7. **相**：诸侯祭祀、会盟或朝见天子时，主持赞礼的司仪官。
8. **冠 guàn 者**：成年人。古代男子在*二十岁时行加冠礼*，表示成年。
9. **衅钟**：*古代新钟铸成，宰杀牲口，取血涂钟行祭*。
10. **钧**：古代重量单位，30 斤为一钧。
11. **庠序**：古代的*地方学校*，后泛指学校。
12. **孝悌**：*善事父母为 “孝”，敬爱兄长为 “悌”*。
13. **《左传》**：*我国第一部叙事详备的编年史著作*，相传为春秋末年鲁国史官左丘明所作。
14. **参乘**：即 “骖乘”，古时站在*车右陪乘或担任警卫*的人。
15. **再拜**：拜两拜，古代一种较重的礼节。
# 下二
1. **元杂剧**：又称*元曲*，是盛行于元代的一种戏曲艺术，*为散曲或杂剧的通称*。其戏剧形式包括*故事情节、曲词、宾白、科介*等。“*四折一楔子*” 是元杂剧最常见的剧本结构形式，即每个剧本一般由四折戏组成，有时再加一个楔子。元杂剧角色分为*旦、末、净、杂*。元曲四大家：*关汉卿、白朴、郑光祖、马致远*。主要代表作有：*《窦娥冤》（关汉卿）《梧桐雨》（白朴）、《倩女离魂》（郑光祖）、《汉宫秋》（马致远）等*。
2. **外**：“*外末*” 的简称，角色名。意为*正角之外的次要角色*。
3. **净**：角色名，俗称 “*花脸*”。
4. **科**：古代戏曲剧本中指示*角色动作、表情*的用语。
5. **正旦**：传统戏曲中的*女主角*。
6. **宫调**：我国古代音乐以宫、商、角、变徵、徵、羽、变宫为七声，以其中任何一声为均可构成一种调式，*凡以宫声为主的调式称 “宫”，以其他各声为主的称 “调”，合 “宫调”*。
7. **卜儿**：元杂剧中的*老年妇女角色*。
8. **话剧**：指以*对话为主*的戏剧形式。话剧虽然可以使用少量音乐、歌唱等，但主要叙述段为演员在台上无伴奏的*对白或独白*。五四运动之后，欧洲戏剧传入中国，中国现代剧兴起，当时被称为 “爱美剧”“白话剧” 或 “真新剧”，1928 年由戏剧家洪深提议名 “话剧”。
9. **嫁奁 lián2**：*陪嫁的财物*。奁，古代妇女梳妆用的镜匣，也指陪嫁的衣物等。
# 下五
1. **三川之地**：指*黄河、洛水、伊水*相交之地。
2. **私门**：对公室而言，*指权贵大臣之家*。
3. **五帝三王**：五帝，《史记・五帝本纪》指*黄帝、颛 zhuān 顼 xū、帝喾 kù、唐尧、虞舜*。*三王，指夏、商、周三代开国君主，即夏禹、商汤和周武王*。
# 下六
1. **监 jiàn 生**：国子监生员的简称，指明清两代在国子监（我国封建时代的中央最高学府）读书的人。*清代乾隆*以后，国子监只存有空名，*地主豪绅可以凭祖先 “功业” 或捐钱取得监生资格*。
2. **炮烙 páo luò**：相传是商代的一种酷刑。用炭烧热铜柱，将有罪者炙烙而死。
3. **刺配**：脸上刺字，发往远地充军。刺，古时的肉刑，在罪犯额面或肌肤上刺字，用墨染上颜色。
4. **丁口**：人口。*成年男子称丁，女子及未满十六岁男子称口*。
5. **童子**：*童生*。科举时代，*还没考取秀才的读书人*，不论年纪大小，都称为 “童生”。
6. **追比**：旧时地方官限期交税、交差等，*过期以杖责、监禁等方式继续追逼*。
7. **东曦既驾**：*太阳已经升起*。东曦，指日神东君。曦，日光。既驾，已经乘车出来。古代传说，日神乘着六龙驾驭的车。
8. **蠢若木鸡**：形容神貌呆笨。《庄子・达生》说，养斗鸡的，要把斗鸡训练得镇静沉着，仿佛是木头雕的，才能够不动声色，战胜别的斗鸡。
9. **学使**：即*提学*，负责一省学校事务，主持岁考、科考两试的官员。  
# 下八
1. **魏征**：字玄成，唐朝政治家。曾任谏议大夫、左光禄大夫，封郑国公，谥文贞，为凌烟阁二十四功臣之一。以直谏敢言著称，是*中国史上最负盛名的谏臣*。
2. **王安石**：字介甫，晚年号半山，临川人，曾被封为荆国公，世称 “王荆公”，卒谥 “文”，又称 “王文公” 。他是北宋著名的政治家，两次出任宰相，坚持推行变法，世称 “*王安石变法*” 。王安石是*唐宋八大家之一*，他在诗、词、散文等方面都有独特的成就，他主张为文应 “有补于世”，“以适用为本” 。存世文集有《临川先生文集》《王文公文集》 。
3. **杜牧**：字牧之，唐京兆万年（现陕西省西安市）人，唐代著名诗人。因晚年居住在长安城南的樊川别墅，故后世称他为 “杜樊川”“樊川先生” 。杜牧的文学作品，诗歌的成就最大，在晚唐诗坛独树一帜。人们将他*和杜甫作比，称他为 “小杜”*；*又将李商隐与他合称为 “小李杜”* 。
4. **苏洵**：北宋文学家，字明允，眉州眉山（今属四川）人。*苏洵与其子苏轼、苏辙合称 “三苏”*，均被*列入 “唐宋八大家”* 。苏洵长于散文，尤擅政论，有《嘉祐集》传世。
5. **疏**：*疏通事理，分条陈述*。属古文体的奏议类，*专指臣下向国君陈述意见的奏疏*。如：《论积贮疏》（贾谊）、《谏太宗十思疏》（魏征）等。  
6. **书**：古代的一种文体，就是*书信*的意思。古人写信，多有题目，说明是写给谁的。信题多为 “报…… 书”“与…… 书”“上…… 书”“答…… 书” 等，如《答司马谏议书》（王安石）等。  
7. **论**：古代*论说文体*中的一种，要求*析理透辟*。分为*政论和史论*两种：政论主要用于发表作者对于时政的见解和主张；史论通过评论历史，总结历史教训，为当时统治者提供治国借鉴，比如《过秦论》（贾谊）
