## 文体特点与策略
### 论述文
1. 概括题（能抄则抄）
	1. 局部概括
	2. 辨析+概括：侧重点有何不同？
	3. 特殊句式概括：给...下一个简单定义
	4. 迁移概括：材料讲A，迁移到B
2. 论证XX类
	1. 论证思路：
		1. “提分解”式：提出论题，分析问题（展开论证），解决问题（得出结论）
		2. 驳论式：提出错误观点，批驳错误观点，提出正确观点
	2. 论证结构：
		1. 总分/总分总式结构
		2. 正反对照式结构
		3. 递进式结构（提出问题-分析问题-解决问题）
		4. 并列式结构
		5. 综合式
	3. 论证方法：引用论证、比喻论证、举例论证、正反对比论证（反面论证）、因果论证、假设论证
	4. 论点提出的特点
		1. 以设问/疑问/反问的方式提出论点
		2. 开门见山地提出中心论点
		3. 针对生活中存在的现象提出论题，经过分析归结出中心论点
		4. 叙述作者的一段经历后提出论点
		5. 从故事中提出问题，...
		6. 摆事实讲道理，...
	5. 论据呈现的特点：
		1. 论据真实可靠
		2. 论据具有典型性
		3. 论据丰富多元
	6. 论证语言的特点
		1. 用词：衔接语，关联词，修饰词→逻辑性强
		2. 句式：反问句，感叹句等→情感性强
		3. 用词的科学性和准确性→准确度高
		4. 修辞手法：比喻排比反问等→生动形象
3. 阐释题：题干中给出某观点，请结合材料分析
	- **先抄文章材料依据**，再结合题干分析
4. 作用题：
	- 根据论述文文体特征（论证/反驳/引出了某观点，丰富了论证手法等）来答
### 科普文
1. 说明方法：下定义，举例子，打比方，列数字，分类别，作比较，画图表，摹状貌等
2. 说明顺序：空间顺序，时间顺序，逻辑顺序
3. 结构特点：“倒金字塔”
4. 科普文的要素
	1. 科学性：科学术语，科学研究成果
	2. 逻辑性：行文结构，逻辑清晰；关联词的使用
	3. 准确性/严谨性：确凿的事实，精确的数字
	4. 文学性/生动性/趣味性：修辞手法，多种表达方法
	5. 通俗性：比喻，类比，图标等方式使其通俗化
### 访谈
1. 文体特征：针对性；专题性；典型性
2. 提问技巧
	1. 趣问（消除陌生感，拉进双方距离）；直问；推问（逻辑推理）；旁问（有意岔开，先说写别的事情制造轻松气氛）；在“错”中逆向提问
	2. 追问；延伸；对比
3. 评价记者的提问
	1. 是否充分准备
	2. 问题设计能否让受访者充分表达看法，让听众全面了解事件
	3. 态度是否中立（不应有引导性，或掺杂自己的看法）
### 新闻与新闻评论
#### 新闻与新闻评论的区别
新闻
- 核心功能：告知事实，传递信息
- 写作原则：客观真实，准确全面
- 内容侧重：5W1H，呈现多方事实与观点
- 语言风格：平时准确，以叙述为主
新闻评论
- 核心功能：阐释观点，引导舆论
- 写作原则：观点鲜明，论证有力
- 内容侧重：在事实基础上，分析事件的原因，意义，影响，趋势，问题，对策
- 语言风格：可以有倾向性，常用设问、比喻等修辞手法，更具说服力和感染力

答题分点（目的；语言风格；内容特点）
新闻：客观叙述事实；多角度呈现，不掺杂立场；语言平实准确
评论：观点鲜明，立场明确；引导呼吁，提出对策；语言生动通俗
### 调查报告
1. 文体特点
	1. 内容真实
	2. 材料性强：列举相关事例，统计数字以及各方意见
	3. 针对性强：针对某一综合性或是专题性问题展开
	4. じあ叙夹议
	5. 语言简洁：相比通讯等文体，表达更为严肃
### 书序
1. 要素
	1. 写作缘起/创作背景
	2. 权属核心主旨与定位
	3. 内容框架与结构简介
	4. 内容特色与亮点
2. 自序（侧重心路，缘起，内容解读，致谢）与他序（侧重作者评价，书籍价值拔高，推荐理由）
### 传记
1. 文体特点
	1. 真实性
	2. 文学性：艺术手法的使用（自传：第一人称；他传：第三人称）
	3. 概括性：选择高度概括人物特点的事迹
	4. 通俗性
	5. 倾向性（评价性）：如褒扬传主
2. 传记结合文学类
	1. “列传”与历史背景：将个人命运与时代变迁结合，增强叙事的真实感和厚重感
	2. 按时间顺序串联人物典型事迹
	3. 于冷静客观的史传笔法叙事，情感深沉克制，耐人寻味
	4. 为平凡者立传，凸显精神价值

## 字
### 字音字形
### 造字法
1. 象形：描摹实物轮廓形成基础字符（如"日""鸟"）
2. 指事：使用抽象符号或在图形上加上指示性符号来表示意义，例如“上”、“下”字是在“一”的上方或下方加上标示符号。“刃”以一点表示刀刃。还有本、末等
3. 会意：将两个或多个象形字组合在一起，表达新的意义，例如“休”字由“人”和“木”组合而成，表示人倚靠在树上
4. 形声：由表意形旁与表音声旁组合构成
（转注和假借）
## 词语成语
### 构词方式
- 单纯词
	- 单音节词：如牛、走、大
	- 多音节词
		- 联绵词：两个音节连缀成义，不可拆分。
			- 双声词：声母相同，如仿佛、澎湃、忐忑
			- 叠韵词：韵母相同（相似），如彷徨、蹒跚、从容
			- 其他（非双声叠韵）：如芙蓉 、蝴蝶、鸳鸯、葡萄、垃圾
		- 音译词：如咖啡、沙发
		- 拟声词：如扑通、哗啦、叮咚
		- 叠音词：如姥姥、奶奶、纷纷
- 复合词：有两个及以上的语素
	- 并列式：语素意义相近、相关或相反，如语言、道路、好歹、开关
	- 偏正式：前一个语素修饰后一个，如红旗、象牙、迟到、狂热
	- 补充式：后一语素补充说明前一个，如提高、扩大、说明
	- 主谓式：字面意思（区分补充式），如地震、头痛、胆怯
	- 动宾式：字面意思，如司机、伤心、动员
	- 名量式：后面的语素是量词，如花朵、枪支、纸张、人口
	- 重叠式：如妈妈、姐姐、条条框框

※如何区分叠音词和重叠式？
- 拆开还有老意思→重叠式
- 拆开没意思或意思大变→叠音词
## 标点符号
### 作用
- 引号
	1. 标识直接引用的内容
	2. 标识着重论述或强调的内容
	3. 标识特定称谓
	4. 标识特殊含义
	5. 标识否定或讽刺
- 破折号
	1. 标示注释内容或补充说明
	2. 标识插入语（也可以逗号）
	3. 标识总结上文或提示下文（也可以冒号）
	4. 表示话题转换
	5. 表示声音延长
	6. 标识话语中断或间隔
- 省略号
	1. 标识引文省略
	2. 标识列举的省略
	3. 标识语意未尽
	4. 标识说话断断续续
	5. 标识沉默不语
- 冒号
	1. 用于总说性词语后，标识提示下文
	2. 标识总结上文
	3. 标识注释说明

## 病句
### 错误类型
1. 语序不当
	1. 多项定语次序不当：_她是一位优秀的有20年教学经验的国家队的篮球女教练。_
	2. 多项状语次序不当：_许多同学在教室里昨天热情地为他鼓掌。_
	3. 定语状语位置不当：_这个问题在群众中广泛引起了议论。_
	4. 虚词位置不当：_如果趁现在不赶快检查一下肺功能，就会耽误病情。_
	5. 数词使用不当：_他把烧饼翻来覆去地烤了两个，觉得还不熟。_
	6. 主客体颠倒：_艾青的《大堰河——我的保姆》对中学生是不陌生的。_
	7. 并列短语位置不当：_这是一本好书，它能催人进取，促人警醒，引人深思。_
	8. 分句位置不当：_他不仅获得了全校第一名，而且打破了市纪录。_
2. 搭配不当
	1. 主干成分搭配不当：_他的革命精神时刻浮现在我眼前。_；_我们阅读了许多名著，提高了自己的写作水平。_；_秋天的北京是个美丽的季节。_
	2. 枝叶成分搭配不当：_他投了两个球，都投中了，表现出崇高的球艺。_；_大家把教室打扫得干干净净，整整齐齐。_；_他跑得满地都是汗。_
	3. 呼应成分搭配不当
		1. 关联词搭配不当：_只要增加投入，才能使粮食产量稳步增长。_
		2. 两面对一面（注意区分可以搭配和不可搭配的情况）：_能否取得好成绩，关键在于态度要端正。_
3. 成分残缺
	1. 主语残缺：_通过这次实践活动，使我们增长了见识。_
	2. 谓语残缺：_我们沿着革命先辈的光辉足迹。_
	3. 宾语残缺：_我们要学习雷锋同志助人为乐。_

### 关联词
1. 并列关系：既...又...，有时...有时...，一边...一边...，**不是...而是...**
2. 选择关系：**不是...就是...**，宁可...也不...，与其...不如...，是...还是...，或者...或者...
3. 递进关系：不但...而且...，不仅...还...
4. 承接关系：首先...然后...
5. 因果关系：因为...所以...
6. 转折关系：虽然...但是...，尽管...可是...
7. 条件关系：只要...就...，只有...才...，无论（不管、不论）...都...，除非...才...
8. 假设关系：如果...就...（让步假设：即使...也...）
## 逻辑的力量

### 四个“律”
- **同一律**：概念前后一致。公式：A是A。错误：偷换概念。
- **矛盾律**：不能同时肯定两个矛盾判断。公式：A不是非A。错误：自相矛盾。
- **排中律**：两个矛盾判断必有一真。公式：A或非A。错误：模棱两可。
- **充足理由律**：判断必须有真实且充分的前提。错误：理由虚假、循环论证。
### 逻辑谬误
- **形式谬误**：推理形式错误（如肯定后件）。
- **非形式谬误**：诉诸人身/情感/权威/公众、稻草人、滑坡、虚假两难、循环论证。
### 三段论
由大前提、小前提推出结论。  
例：人皆会死（大），苏格拉底是人（小），故苏格拉底会死（结）。  
规则：三项无歧义、中项至少周延一次、前提否定则结论否定。
### 反证法
欲证P真，先假设非P真，推出矛盾，故P真。  
例：证“至少有两个锐角”——假设至多一个锐角→内角和＞180°，矛盾。
### 归谬法
欲驳Q假，先假设Q真，推出荒谬结果，故Q假。  
例：“所有命题都是假的”为真→自身也假，矛盾。

### 哲学观点
- **迈克尔·桑德尔**，提出 **“社群主义”**，个人身份由社群和历史塑造，因此与生俱来负有“团结的义务”，包括为祖辈行为负责，也就是当代人需要为历史事件负责
- **背景：“大脱嵌”**。现代社会的个人乃是“大脱嵌”的产物，其从家国天下的共同体中游离出来，成为自我本真性的原子化个人。
	- **查尔斯·泰勒**虽然认为现代的个人是一个具有本真性的自我，但强调这一具有本真性的自我只有在一定的社会与文化的构架之中才能获得自我的理解和认同
	- “大脱嵌”之后，家国天下的秩序与现代人的自我，都面临着一个“再嵌化”：自我要置于新的家国天下秩序中得以重新理解，而家国天下也在自我的形塑过程中得以重新建构。那是一个交互性的“再嵌”，是一个走向理想世界的能动过程。

## 二元关系的思考
语言是社会的镜鉴。近来，一幅关于生活状态的对比描摹在青年群体中广泛流传 ——“从从容容、游刃有余” 与 “匆匆忙忙、连滚带爬”。这看似简单的两组四字词，精准勾勒出两种迥异的人生节奏与生命姿态。前者指向一种气定神闲、一切尽在掌握的优雅境界，后者则刻画了一种疲于奔命、被动应对的局促现实。

如何分析二元材料？
- 首先，二者肯定不是非黑即白的
- A一定好吗？B一定坏吗？有没有可能B是一种值得尊重的事实？
	- 可能的论点：警惕虚假的A，赞美真实的B。
- A和B是不是可以相互转化？
	- 可能：B是A的必经过程，A是B的最终结果。
	- 可能：躯体/行动上处于B状态，灵魂/心境上保持A状态。
