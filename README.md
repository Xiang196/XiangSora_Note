## 1.3. 🚀 使用建议

- 推荐使用 [Obsidian](https://obsidian.md/) 查看和编辑本仓库（支持双链跳转、标签、图谱等）
- 所有笔记均为 Markdown 格式，支持直接阅读或导出 PDF
- 若你不是 Obsidian 用户，也可以：
  - 使用 VSCode 等 Markdown 编辑器打开
  - 浏览 GitHub 上的原始 `.md` 文件
